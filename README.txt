TOUCH GRASS — first website prototype

Files:
- index.html: complete responsive website and playable garden game.

How to preview:
Open index.html in a modern browser.

How to deploy:
Upload the contents of this folder to a GitHub repository. For Render Static Site, connect the repository, leave Build Command blank, and set Publish Directory to . (the repository root).

Current scope:
- Garden game runs in the browser.
- Grass Points and garden progress are saved in that browser's local storage.
- No wallet connection, smart contract, token minting, or Buy button is included.
- Points are not tokens and are not redeemable.
